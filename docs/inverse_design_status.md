# 逆解析学習機の現状ステータス

更新日: 2026-07-16

## ゴール

配合情報から複数物性を予測する順方向モデルを学習し、用途仕様に近い候補配合を推薦する逆解析の学習機を作る。

ここでの逆解析は、物性値から直接1つの処方を回帰する方式ではない。順方向モデルを採点器として使い、既存配合に近い候補を生成して、目標物性との近さで順位付けする方式である。

## 現在できていること

- データセット論理名を `config/data_catalog.local.json` で管理し、Notebookやスクリプトから `processed_main` を読み込める。
- 物性列を説明変数から除外し、配合情報だけで物性を予測する前処理が `src/plastech/modeling.py` にまとまっている。
- Random Forest、XGBoost、LightGBM の順方向モデルを同じ入口で作れる。
- 通常ランダム分割、完全一致配合グループ、主PVC、主可塑剤、主PVC+主可塑剤の評価ができる。
- OOF予測を使って、目標値候補ごとのデータ密度と局所誤差を確認できる。
- `DesignBrief` と `TargetSpecification` で、用途別の主目標・副目標を定義できる。
- 既存配合ライブラリから、主PVC・主可塑剤が同じ親配合を補間して仮想候補を生成できる。
- 予測物性、重み付き `design_score`、Pareto最適性、材料系列の重複抑制を使って推薦候補を出せる。
- `scripts/run_inverse_design.py` で、Notebookを開かずに逆解析候補を出力できる。
- 推薦候補ごとに、未達物性と親配合A/Bからの配合差分をCSVで確認できる。

## 現在の到達点

学習機の試作としては、順方向学習から候補推薦まで一通り動く段階に到達している。

一方で、現時点の候補は「実験候補のたたき台」であり、最終処方ではない。理由は以下である。

- 予測誤差があるため、予測値が目標内でも実測で外れる可能性がある。
- 仮想候補は既存配合の補間であり、原料併用可否、加工性、コスト、法規、在庫はまだ判定していない。
- 目標値と許容幅は初期仮説であり、製品仕様が固まれば更新が必要である。
- 新規材料系列への外挿性能は、通常ランダム分割より厳しいグループ評価で継続確認する必要がある。

## 次に進める作業

1. `scripts/run_inverse_design.py --concept all --output-dir <dir>` で全用途の推薦候補CSVを出す。
2. `*_candidate_summary.csv` で、候補ごとの予測物性、未達物性、Pareto最適性を見る。
3. `*_parent_formulation_deltas.csv` で、親配合A/Bから大きく変わる原料を確認する。
4. 原料併用可否、総配合量、加工性、コスト、法規、在庫・調達性のチェック列を候補表に追加する。
5. 実験候補を3〜5件に絞り、実測結果を `processed_main` に戻して再学習する。
6. 実測追加後に、OOF誤差、候補順位、外れ候補の傾向が改善したか確認する。

## 実行例

```bash
python3 scripts/run_inverse_design.py \
  --concept all \
  --n-estimators 800 \
  --seed-count 30 \
  --partners-per-seed 5 \
  --top-n 5 \
  --output-dir outputs/inverse_design
```
